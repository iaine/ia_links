Methods

Use the IA Snapshot tool to retrieve archived versions of web pages from the Internet Archive Wayback Machine.

How to Use

  1. Paste one URL per line into the input box.
  2. Choose whether duplicate results should be shown.
  3. Select a timestamp grouping if required.
  4. Select an output format.
  5. Click Submit.

Output Formats

  • Text
    Plain text list of snapshot URLs.
  • CSV
    Suitable for spreadsheets and bulk processing.
  • HTML
    Generates a clickable links page.

Notes

Depending on the number of URLs submitted, processing may take longer for larger input lists.
